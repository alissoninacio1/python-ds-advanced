## Phase 1: Python Fundamentals
The goal of this phase is to understand the language syntax and core programming logic.

* **Variables and Data Types:** `int`, `float`, `string`, `bool`.
* **Operators:** Arithmetic (`+`, `-`, `*`, `/`, `//`, `%`), logical (`and`, `or`, `not`), and comparison operators.
* **Conditional Statements:** `if`, `elif`, `else`.
* **Control Flow Loops:** `while` and `for` loops (utilizing `range()`).
* **Functions:** Definition (`def`), parameters, arguments, and return values (`return`).

---

## Phase 2: Data Structures
Organizing and manipulating data efficiently in memory.

### Built-in Data Structures
* **Lists (`list`):** Mutable, ordered sequences. Methods: `append()`, `pop()`, `sort()`, and list comprehensions.
* **Tuples (`tuple`):** Immutable, ordered sequences. Used for data that should not change.
* **Dictionaries (`dict`):** Key-value pairs. Optimized for fast lookups.
* **Sets (`set`):** Unordered collections of unique elements. Used for union and intersection operations.

### Advanced Concepts
* **Stacks:** LIFO (Last In, First Out) implementation.
* **Queues:** FIFO (First In, First Out) implementation using `collections.deque`.
* **Linked Lists:** Understanding the concept of nodes and pointers.

## Phase 3: Basic Statistics with Python
Applying statistical concepts using pure Python alongside the `math`, `statistics`, `NumPy`, and `Pandas` libraries.

### Descriptive Statistics
* **Measures of Central Tendency:** Mean, Median, and Mode.
* **Measures of Dispersion:** Variance, Standard Deviation, Range, and Quartiles.
* **Basic Visualization:** Histograms and Boxplots (using `Matplotlib` or `Seaborn`).

### Correlation and Probability
* **Pearson Correlation:** Understanding the strength of relationships between two variables.
* **Basic Probability:** Sample space, events, and simple probability calculations.
